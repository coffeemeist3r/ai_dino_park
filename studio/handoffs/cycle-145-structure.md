# Cycle 145 — Structure Handoff

**Intent:** Close Milestone 16. Its last unchecked arc is the reachability register (**501**) — CHARTER
v7's bar as a machine-checked list rather than a paragraph each verdict re-argues by hand. Last cycle's
Structure-smith deferred it in writing, on the grounds that its first entries would be the founding
claims and one of those claims was about to change a few hours later. It did change: 512 gave every
ground the roster wakes on a recorded founder and deleted `isOrigin`. The ground has settled, so build
the instrument that pins it. *Build the truth, then the thing that says when it stops being true.*

**Added to Structure Track:** none — drained from queue (**4 open ≥ X=4**: 495, 501, 515, 509). Fifth
cycle running that the queue has been at or over cap; no brainstorming, per the cap rule.

**Chosen this cycle:** **BACKLOG-501** — the reachability register.

**Why this one over the other three.** 495 (the declared founding fixture) is the same finding pointed
at *specs*; 501 points at the *shipping park*, and its item text says the two pair — build the claim
before the fixture that lets specs opt into variations of it. 515 (the runner's serial/parallel split)
is a test-infrastructure item filed last night with a live reproduction and no urgency beyond a
standing red the studio has already learned to read. 509 (the tithe) is the biggest player-visible
item on the queue and deliberately not this cycle's: its own text leaves two design decisions open and
warns that the *milder* version reddened thirteen specs, which is precisely the kind of founding-constant
move 501 exists to make safe. Ship the register, then move the constant.

**The collision check.** The lore track is 516 (`pioneer.ts` + `standings.ts` + the book). The register
lives in `world/` beside `founding.ts` and *reads* the founding surface rather than writing it — so the
two tracks meet at exactly one file, `founding.ts`, and only if 516 chooses to record founding *kind*
there. Noted for the Designer: if it does, the register must take the new fact as an entry rather than
re-deriving it, and the Coder should land 516 first.

**The reachability bar, named up front.** A register is an instrument, and an instrument that only
watches is the exact failure mode CHARTER v7 was written about. So this item ships under a condition the
Designer must hold: **the register's first walk is not allowed to be decorative.** Every entry names a
system, the founding fact that makes it reachable, and how it is checked; the walking test fails on any
entry that no longer holds; and **whatever the first walk finds dark ships fixed in this same cycle.**
If the walk comes up all-green, the register must say so about claims the park has *never* checked
rather than about the four already covered by bespoke tests — an all-green register over a hand-picked
list is a paragraph with a `.test.ts` extension.
