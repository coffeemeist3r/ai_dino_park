## The scoping call, stated plainly

The item's literal option (a) is "a lint over `tests/e2e/*.spec.ts` requiring one `foundingState` call
per file". Counted tonight: **251 of 280 spec files** do not call it. A lint that reds on 251 files is
not a rule, it is a 251-file mechanical edit wearing a rule's clothes, and CHARTER v6 caps an item at
~15 files for good reasons. So the rule ships as the standard ratchet: **the lint is absolute for any
file not in a frozen baseline, and the baseline may only ever shrink.** New specs must declare from
tonight; the 251 are grandfathered by name and the list is asserted to be exactly as long as it is, so
a file leaving it can never silently be replaced by a file joining it. That is the whole of 533's
complaint answered — silence stops meaning `'as-shipped'` by default *for anything written after
tonight* — at a size one Coder fire can carry, and it generates the evidence the item asked for as a
side effect: the baseline's length is the count, published and falling.
