# Cycle 170 — Lore Handoff

**Theme: friendship you can hear in a crowd.**

Milestone 22 has one lore arc left, and it is the one about the *group*. Every voice beat this
milestone shipped so far is a pair talking — the keeper and a dino (193), a crier and its friend
(202). The chorus has been one flat energy-ordered roll across the cast since cycle 45: two
dinos who are each other's closest friend wake exactly as far apart as two strangers of the same
temperament, and the dino nobody is close to sings in the middle of everybody like it belongs
there. This cycle makes the bond graph audible *at the scale of a ground*: the pair lands
together, pips interleaved, and the loner comes in a beat after the rest have stopped.

**The reachability problem this arc has to solve first.** The only chorus in the park fires at
07:00, and a fresh save opens at 08:00 — the next dawn is twenty-three real minutes away. 200 and
198 as written build on a beat no ten-minute sitting can reach. The chorus needs an occasion a
player walks into, and the park already has one it has never scored: **the keeper crossing onto a
ground.** The residents call as you arrive — once per ground per in-game day, so it is an event
and not a doorbell — and dawn keeps its chorus, reading the same cue list. The Designer should
treat the arrival occasion as part of this arc, not as scope creep: without it the arc is
groundwork.
